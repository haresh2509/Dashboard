# Nothing OS "Together Since" 4x2 Android Widget

Native Android widget (Kotlin) in Nothing style: near-black rounded card, 5x7 dot-matrix day count with faint unlit dots, TOGETHER SINCE label, red heart and white infinity, years/months/days breakdown, and a red dot.

Build the APK with GitHub Actions: open the Actions tab, run "Build Android Widget APK", then download the artifact NothingTogetherWidget-debug-apk.

Add the widget: long-press the home screen > Widgets > Together Since (4x2). Tap the widget to set the wedding date.
